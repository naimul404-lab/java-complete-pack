# Java Complete Pack

A practical Java learning repository covering Java basics, object-oriented programming, collections, exceptions, file handling, and small console projects.

## Requirements

- Java 17 or newer recommended
- Maven or javac can be used to compile the examples

## Structure

- `01_basics/`
- `02_control_flow/`
- `03_oop/`
- `04_collections/`
- `05_exceptions_files/`
- `06_collections_more/`
- `07_projects/`

## Compile and run

```bash
javac 01_basics/HelloWorld.java
java HelloWorld
```
